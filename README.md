# 🧥 Invisible Cloak (OpenCV Project)

📌 **About**
This is a computer vision project built using Python and OpenCV that creates an "invisibility cloak" effect. It detects white color using HSV color space and replaces it with the previously captured background, making the object appear invisible in real time.

⚙️ **Tech Stack**
Python, OpenCV, NumPy

🚀 **Features**

* Real-time webcam processing
* Background capture system
* White cloth detection using HSV color range
* Invisible cloak effect using masking
* Noise reduction using morphological operations
* Live preview of original and processed video
